# Hut data

Directories identify applicable versions; filenames identify the lowest spawning height. Each line contains only `seed`, `x` and `z`, sorted by numeric seed, X and Z.

- [Counts by version and height](../../docs/SEEDS.md)
- [File index](index.json): applicable and directly verified versions, paths and record counts.
- [Verification summary](verification.json): 624 positions tested in each of 15 exact-interval representatives, totaling 9360 vanilla queries.
